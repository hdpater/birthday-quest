# Birthday Quest

## Setup for GitHub Pages

1. Push this repo to GitHub (must be public)
2. Go to **Settings → Pages**
3. Under Source, choose **GitHub Actions**
4. Push any commit — the workflow builds and deploys automatically
5. Game will be at `https://YOUR_USERNAME.github.io/birthday-quest/`

> If your repo is named something other than `birthday-quest`,
> edit `vite.config.js` and change `base: '/birthday-quest/'` to match.
